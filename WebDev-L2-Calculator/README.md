# WebDev-L2-Calculator

## OASIS Infobyte Internship – Level 2 Task 1

A responsive and professional calculator built using HTML5, CSS3, and Vanilla JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Clear button
- Backspace/Delete button
- Operator chaining
- Division-by-zero error handling
- Responsive design for mobile and desktop
- Event listeners for calculator interactions
- No use of `eval()`

## Technologies Used

- HTML5
- CSS3
- JavaScript
