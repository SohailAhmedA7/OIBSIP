# WebDev-L2-TributePage

## OASIS Infobyte Internship – Level 2 Task 2

A responsive tribute webpage dedicated to Dr. A.P.J. Abdul Kalam, created using HTML5, CSS3, and Vanilla JavaScript.

## Features

- Hero section with name and tagline
- Tribute image
- Biography section
- Life journey timeline
- Achievements section
- Inspirational quote
- Smooth scrolling interaction
- Responsive design for desktop and mobile
- Multiple background colors
- Professional typography and card-based layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
