# WebDev-L2-LoginAuthentication

## OASIS Infobyte Internship – Level 2 Task 4

A responsive front-end authentication system with registration, login validation, session handling, protected dashboard access, and logout functionality.

## Features

- User registration
- Full name and email validation
- Strong password validation
- Password confirmation
- Duplicate email/account detection
- Login authentication
- Invalid credential handling
- Password visibility toggle
- Protected dashboard
- Session management using browser storage
- Personalized dashboard
- Logout functionality
- Responsive design for desktop and mobile
- Form validation and user-friendly error messages

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
