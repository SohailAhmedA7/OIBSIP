# WebDev-L2-ToDoApp

## OASIS Infobyte Internship – Level 2 Task 3

A responsive and interactive To-Do Web App built using HTML5, CSS3, and Vanilla JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Total task counter
- Pending task counter
- Completed task counter
- Pending and completed task sections
- Empty-state messages
- Local storage support
- Data remains available after refreshing the page
- Responsive design for desktop and mobile
- Input validation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
